# Documentation

Documentation is organized by purpose:

- `project/` contains the project's durable memory: `PROJECT.md`, selective build history, decisions, operating instructions, and component handoff files.
- `technical/` contains focused documentation for implemented subsystems and technical investigations.

The root `README.md` is the authoritative product baseline. `project/PROJECT.md` and the relevant component file are authoritative for current implementation state and the next handoff.
